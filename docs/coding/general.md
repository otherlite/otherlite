# 通用代码规则

- 不写注释解释"做了什么" —— 标识符已经做了这件事。只在"为什么"非显而易见时写一句（绕过某个 bug、外部约束、微妙的不变量）。
- 不留向后兼容的临时垫片，除非用户明确要。要删的代码就彻底删干净。
