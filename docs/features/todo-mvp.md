# Todo MVP

## What

一个最小可用 Web 待办清单应用。用户在一个浏览器窗口内完成"记一件事 → 看到它 → 标记完成 → 清理"的完整闭环。纯前端，无后端、无账户、无需联网。

## Why

MVP 阶段用最少的功能跑通 Todo 产品的核心价值：**写下要做的事 + 跟踪完成进度**。避免被认证、协作、多端同步等"将来再说"的话题拖住。

## How

### 入口

应用在 `apps/todo/` 下，通过 `pnpm dev` 启动后访问浏览器即可使用。

### 功能清单

| 功能 | 用户操作 | 对应用户故事 |
|---|---|---|
| 创建待办 | 在文本框输入文字，按 Enter 或点"添加"按钮 | US-1 |
| 查看列表 | 打开页面即见所有待办，按创建时间倒序排列（新的在上） | US-2 |
| 标记完成/未完成 | 点击待办前的 checkbox | US-3 |
| 编辑文本 | 双击待办文字进入编辑态，修改后按 Enter 或 blur 保存，按 Esc 取消 | US-6 |
| 删除待办 | 点击待办右侧的"✕"按钮 | US-4 |
| 数据持久化 | 所有操作自动保存到浏览器；刷新页面或重开标签页后数据仍在 | US-5 |

### 视觉状态

- **已完成**：文字带删除线，checkbox 显示勾选
- **未完成**：正常文字，checkbox 为空
- **空列表**：显示引导文案「还没有待办，加一条试试」（US-8）

### 键盘操作

全部 P0 操作可仅用键盘完成：

| 操作 | 按键 |
|---|---|
| 聚焦输入框 | Tab（页面加载自动聚焦） |
| 提交新待办 | Enter |
| 勾选/取消 | Tab 到 checkbox → Space |
| 编辑 | Tab 到待办 → Enter（待改进：双击触发） |
| 删除 | Tab 到删除按钮 → Enter |
| 保存编辑 | Enter 或 Tab 离焦 |
| 取消编辑 | Escape |

### 约束

- 单条文本长度上限 200 字符，超出自动截断
- 空白文本（仅空格）不会创建或保存
- 编辑时清空文本视为取消编辑，恢复原文
